Sources & polling interval

Only enabled sources are fetched automatically. The source a region uses is selected with the region above. Downloads follow the source's scan cycle (Rapid Scan 5 min, MTG FCI 10 min, 0° 15 min) as soon as the new scan is available; afterwards the regions using the source are rendered. Custom cycle per source via cycle_minutes in the JSON.
